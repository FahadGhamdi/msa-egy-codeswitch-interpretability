Saved-array statistical recomputation scripts.

See ../REPRODUCIBILITY.md for repository-relative commands, requirements, outputs and limitations, and ../STAGE1_COMMANDS.txt for model-specific Stage1 commands.

The archives listed in REQUIRED_CURVE_ARCHIVES.json and STAGE1_INPUT_INDEX.json are not included in this repository. Supply authorized local copies using the explicit command-line arguments. Aggregate reference outputs are in ../aggregate_results/.

These scripts do not rerun language-model inference. Code availability does not establish access to every input or end-to-end reproduction.
