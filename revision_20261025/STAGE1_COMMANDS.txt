Stage1 statistical recomputation from saved arrays

Requirements: Python 3, NumPy and SciPy. Run the commands below from the repository root. Replace all /absolute/path/... placeholders with local paths and use new output directories.

INPUT AVAILABILITY
The nine archives listed in revision_20261025/reproducibility_extension/STAGE1_INPUT_INDEX.json are not included in this repository. Obtain authorized copies before running archive preparation. The inventory records filenames, sizes and SHA-256 checksums; it is not a download service.

1. Prepare the ALLaM, Gemma and Fanar inputs:

python3 revision_20261025/reproducibility_extension/prepare_stage1_inputs.py --archives /absolute/path/stage1_archives --out /absolute/path/new_stage1/prepared

The preparation script checks the nine archive hashes, 2,932 completion payloads, per-part manifests and nonoverlapping item IDs. It merges the Gemma/Fanar parts and extracts the nested ALLaM core. Inspect PREPARATION_CHECKS.json in the output directory.

2. Obtain the separate Qwen archive:
ELECTRONICS_QWEN_FP32_STAGE1_20261022T113131Z_REVIEW_CORE_SESSION_03.zip
Expected SHA-256: 7e59e13c8aa100102dd86a9ad376b912bd4f632fe896c3faa8409c505a57615d

This Qwen archive is also not included in the repository. Verify its SHA-256 before extracting it to a new directory:

python3 -m zipfile -e /absolute/path/qwen_archives/ELECTRONICS_QWEN_FP32_STAGE1_20261022T113131Z_REVIEW_CORE_SESSION_03.zip /absolute/path/new_stage1/qwen

3. Recompute each model against the public reference CSVs:

python3 revision_20261025/reproducibility_extension/reproduce_stage1.py --input /absolute/path/new_stage1/qwen/ELECTRONICS_QWEN_FP32_STAGE1_20261022T113131Z --out /absolute/path/new_stage1/analysis/Qwen --expected revision_20261025/aggregate_results/verified_stage1_analysis/Qwen

python3 revision_20261025/reproducibility_extension/reproduce_stage1.py --input /absolute/path/new_stage1/prepared/allam/ELECTRONICS_ALLAM_FP32_STAGE1_20261023_NIGHT --out /absolute/path/new_stage1/analysis/ALLaM --expected revision_20261025/aggregate_results/verified_stage1_analysis/ALLaM

python3 revision_20261025/reproducibility_extension/reproduce_stage1.py --input /absolute/path/new_stage1/prepared/merged/gemma-2-9b --out /absolute/path/new_stage1/analysis/Gemma --expected revision_20261025/aggregate_results/verified_stage1_analysis/Gemma

python3 revision_20261025/reproducibility_extension/reproduce_stage1.py --input /absolute/path/new_stage1/prepared/merged/Fanar-1-9B --out /absolute/path/new_stage1/analysis/Fanar --expected revision_20261025/aggregate_results/verified_stage1_analysis/Fanar

OUTPUTS AND VALIDATION
Each model writes six statistical CSVs and PORTABLE_RECOMPUTATION.json, together with input hashes and diagnostic JSON files. The earlier audit reported 627,120 numerical field comparisons across the four models, with zero difference in that environment. The implemented absolute tolerance is 1e-10 (rtol=0). These are numerical comparisons, not independent hypothesis tests. The commands in this guide were checked against script interfaces and repository paths; they were not rerun with the external archives for this documentation update.

LIMITATIONS
The analyses start from stored item arrays. They do not recreate the 600 FP32 reference-unit forwards per model, resolve historical BF16 discrepancies, or run new k-specific random controls. Output directories must be outside the frozen input directories. The scripts stop on failed checks; no automatic error-retry workflow is provided.
